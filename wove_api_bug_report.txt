WOVE API BUG REPORT
Date: 2026-02-22
Endpoint: GET /api/v1/external/tariffs/lookup
Issue: Section 301 tariff (US_301_9903_88_03, 25%) missing from additionalDuties for specific HTS codes

================================================================================
SUMMARY
================================================================================

For certain HTS codes originating from China (CN), the Wove API is not returning
the Section 301 List 3 additional duty (programCode: US_301_9903_88_03, rate: 25%)
in the additionalDuties array. As a result, the applicableRate returned is 20%
(FENTANYL 10% + IEEPA 10%) instead of the correct 45%+ total.

CRITICAL: This is not a question of tariff interpretation. Your own tariff simulator
on wove.com returns the correct rate of 47.1% for HTS 3506.91 from China, which
includes Section 301. This proves your backend database has the correct Section 301
classification for these codes — the data exists, it is simply not being surfaced
through the API response. The API and your own UI are inconsistent for the same
HTS code and origin country combination.

================================================================================
AFFECTED HTS CODES (confirmed via API)
================================================================================

1. HTS: 3506.91 (Adhesives based on polymers / rubber)
   Query:  hsCode=3506910000, originCountry=CN, destinationCountry=US
   API returns:
     applicableRate: 20%
     baseRate: 0%                                   ← WRONG: MFN base should be 2.1%
     additionalDuties: [FENTANYL 10%, IEEPA 10%]   ← Section 301 25% MISSING
   Your simulator shows: 47.1%

   Total undercount: 27.1%
